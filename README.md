# Senior Legacy

A responsive client-side web application built to showcase interactive front-end logic and UI design.

## 🚀 Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** Firebase

## ✨ Key Features
* Dynamic DOM Manipulation for interactive workflows.
* Clean, zero-dependency client-side architecture.
* Fully responsive layout optimized for all device sizes.

## 🛠️ Setup & Running Locally
1. Clone or download this repository.
2. Open `index.html` in any web browser.
